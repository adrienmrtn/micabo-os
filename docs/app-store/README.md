# App Store — micabo

Kit listing iOS : storyboard ASO (5 frames) puis maquettes UI.

1. Lire [`storyboard.md`](storyboard.md) — ordre, copy, listing.
2. Les images viennent de [`frames.html`](frames.html) (UI Designer).

```bash
cd docs/app-store
npm install
npm run render
```
